# A little room for Markdown

Read your project notes. Make a quick edit. Get back to work.

## Keep the useful things close

- **Recent files** — return to the document you opened before.
- **Pinned files** — keep project notes at the top with ⌘D.
- **Reading position** — pick up where you left off.

## Everything in its place

| Feature | Shortcut | Available |
| :--- | :---: | :---: |
| Read / edit | ⌘E | ✓ |
| Pin a file | ⌘D | ✓ |
| Find text | ⌘F | ✓ |
| Save your changes | ⌘S | ✓ |
