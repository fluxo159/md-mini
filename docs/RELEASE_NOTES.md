# MD Mini 1.0.1

Switch document tabs with **⌘←** and **⌘→** in both reading and editing modes.

- **⌘←** — previous tab.
- **⌘→** — next tab.
- New documents prefer the same native tab group.
- Both actions are listed in the View menu.
- With a single tab, Command-arrow retains the normal text-navigation behavior. Modal dialogs keep their own keyboard handling.

Download **MD-Mini-macOS-arm64.zip**, unzip, and replace the installed **MD Mini.app** in Applications. The interface is in Russian; English and Russian instructions are in the repository.

Targets macOS 13+. Tested on macOS 27.2.1 with Swift 6.4.2. Older macOS versions and Intel Macs have not been tested. The binary is signed ad hoc, not Apple-notarized; macOS may ask for approval before opening it.

The `SHA256SUMS.txt` attachment lists the archive checksum.
